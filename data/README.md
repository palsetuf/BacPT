# Example input

`example_ordered_proteins.faa` is a small synthetic protein FASTA showing the
input format expected by the BacPT inference workflow. FASTA record order is
treated as genomic protein order: the first record is model position 0, the
second is position 1, and so on.

The sequences are provided only as a format and smoke-test example. They are
not a biological dataset or a validation benchmark. Follow the instructions
in the [BacPT-small](https://huggingface.co/palsetuf/BacPT-small) or
[BacPT-large](https://huggingface.co/palsetuf/BacPT-large) repository to run
the model.
